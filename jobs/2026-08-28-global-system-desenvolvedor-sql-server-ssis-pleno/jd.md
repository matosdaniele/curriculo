A Global System busca Desenvolvedor(a) SQL Server Pleno com sólida experiência em desenvolvimento e manutenção de bancos de dados relacionais, com foco em SQL Server e SSIS.

Será responsável por modelagem, otimização e integração de dados, atuando de forma colaborativa com equipes de desenvolvimento, infraestrutura e BI.

### Principais responsabilidades

- Desenvolvimento de procedures, views, functions, triggers e scripts complexos em T-SQL;
- Tuning e otimização de queries e planos de execução;
- Modelagem de dados conceitual, lógica e física;
- Desenvolvimento e manutenção de processos ETL com SSIS;
- Integração de dados entre sistemas;
- Apoio a migrações de dados e atualizações de SGBDs;
- Monitoramento e resolução de gargalos de performance;
- Atuação em conjunto com times de Desenvolvimento, Infraestrutura e BI;
- Garantia da integridade, consistência e segurança dos dados;
- Automação de processos utilizando SQL Server Integration Services (SSIS).

### Requisitos indispensáveis

- Experiência sólida com desenvolvimento em Microsoft SQL Server;
- Domínio de T-SQL;
- Vivência com procedures, views, triggers, functions e índices;
- Experiência com Integration Services (SSIS) e integrações de dados;
- Conhecimento em otimização de consultas e planos de execução;
- Familiaridade com versionamento de código (Git);
- Experiência em metodologias ágeis (Scrum/Kanban);
- Conhecimentos básicos em DevOps.

### Formação

- Graduação completa em Ciência da Computação, Engenharia da Computação, Sistemas de Informação ou áreas correlatas.

### Diferenciais

- Certificação ITIL;
- Certificações Microsoft em SQL Server;
- Experiência em projetos de integração e migração de dados.
