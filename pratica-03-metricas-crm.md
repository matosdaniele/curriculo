## Glossário — explique sem olhar

Cubra a definição com a mão e diga em voz alta:

| Termo | Sua explicação (escreva depois de falar) |
|-------|------------------------------------------|
| Jornada | |
| Régua | |
| Segmento | |
| Coorte | |
| Churn | |
| LTV | |
| Holdout / controle | |
| Impacto incremental | |
| Atribuição | |

**Gabarito curto**
- **Jornada:** sequência de contatos/ações no relacionamento  
- **Régua:** sequência automática de mensagens (boas-vindas, reativação…)  
- **Segmento:** grupo com perfil comum  
- **Coorte:** quem entrou no mesmo período  
- **Churn:** saída/desengajamento (definição do time)  
- **LTV:** valor ao longo do relacionamento  
- **Holdout:** quem não recebe a campanha, para comparar  
- **Impacto incremental:** resultado a mais vs controle  
- **Atribuição:** qual contato recebe crédito da conversão (com limite)

## Mini-caso (escreva 5 linhas)

Cenário: régua de reativação por e-mail + WhatsApp para associados inativos 90 dias.

1. Que métricas você olharia na 1ª semana?  
2. Como saberia se “funcionou”?  
3. Que viés pode existir se olhar só quem clicou?

**Resposta-modelo (não copie na entrevista — internalize):**  
1. Entrega, abertura, clique, conversão (ex.: voltou a transacionar), opt-out.  
2. Comparar com holdout: impacto incremental, não só taxa de clique.  
3. Quem clica já é mais engajado — correlacão ≠ causalidade.
